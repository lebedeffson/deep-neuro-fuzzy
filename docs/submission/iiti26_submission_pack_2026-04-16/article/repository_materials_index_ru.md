# Индекс материалов по статье

Файл фиксирует актуальный состав материалов для финальной сборки статьи.

## Финальные версии (основные)

- `docs/iiti26_final_ru.md` и `docs/iiti26_final_ru.docx` — итоговая компактная версия на русском языке.
- `docs/iiti26_final_en.md` и `docs/iiti26_final_en.docx` — итоговая компактная версия на английском языке.
- `docs/iiti26_full_ru.md` и `docs/iiti26_full_ru.docx` — полная версия на русском языке.
- `docs/iiti26_full_en.md` и `docs/iiti26_full_en.docx` — полная версия на английском языке.

## Дополнительные рабочие версии

- `docs/iiti26_full_article_ru.md` и `docs/iiti26_full_article_ru.docx` — расширенный русский рабочий вариант.
- `docs/iiti26_full_paper_draft_en.md` и `docs/iiti26_full_paper_q2_en.docx` — расширенный английский рабочий вариант.
- `docs/iiti26_camera_ready_sections_en.md` и `docs/iiti26_camera_ready_sections_en.docx` — компактные секции для camera-ready.

## Ссылки и требования

- `docs/iiti26_references_skeleton_en.bib` — библиография для английской версии.
- `docs/iiti26_requirements_checklist_ru.md` — контроль требований конференции.
- `docs/article_readiness_ru.md` — статус готовности по разделам.

- `docs/artifacts/README.md` — описание набора артефактов и назначение файлов.
