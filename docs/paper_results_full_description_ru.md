# Полное Описание Результатов Для Статьи

## Экспериментальный протокол

Для оценки моделей использован единый reproducible benchmark на 5 реальных табличных датасетах (diabetes, linnerud_weight, breast_cancer, wine_binary, digits_binary) с тремя seed (19, 23, 29).
Протокол включает четыре fuzzy-архитектуры: Shallow Fuzzy, Stacked ANFIS, Hierarchical ANFIS и Deep Fuzzy Feature Learning (DFFL).
Для DFFL использовался профиль `quality_auto`, который адаптивно выбирает более «quality-ориентированную» конфигурацию под тип задачи и размер данных.
Полный машинно-читаемый отчёт сохранён в `docs/artifacts/ruanfis_paper5x3_report.json`.

Качество оценивалось по задачно-специфичной метрике: RMSE для регрессии и F1 для бинарной классификации. Сложность оценивалась по структуре rule base (total/active rules), устойчивость — по межсидовой стабильности активных правил (Jaccard).

## Итоговые наблюдения

1. По интегральному качеству (Avg Rank) лучшей оказалась модель **Hierarchical ANFIS** (Avg Rank = 2.000).
2. По устойчивости интерпретации (Avg Active Rule Jaccard) лидирует **Shallow Fuzzy** (0.2673).
3. Структурная сложность моделей различается существенно: более «глубокие» варианты демонстрируют более высокий rule budget, что даёт прирост качества на части наборов, но увеличивает стоимость интерпретации и сопровождения.
4. Победитель зависит от датасета: не наблюдается единственной архитектуры, которая доминирует на всех пяти наборах одновременно.

## Детализация по датасетам

- **diabetes** (RMSE): лучший результат у **Shallow Fuzzy** (0.1944).
- **linnerud_weight** (RMSE): лучший результат у **Hierarchical ANFIS** (0.2949).
- **breast_cancer** (F1): лучший результат у **Stacked ANFIS** (0.9795).
- **wine_binary** (F1): лучший результат у **Hierarchical ANFIS** (0.9577).
- **digits_binary** (F1): лучший результат у **Stacked ANFIS** (1.0000).

## Дополнительная верификация на крупном наборе

На наборе `california_housing` (`20640` объектов, `seed = 19, 23, 29`) внутри нейро-нечёткой группы лучший результат показал **Stacked ANFIS** (`RMSE = 0.1159`), далее идут **Hierarchical ANFIS** (`0.1195`), **DFFL** (`0.1350`) и **Shallow Fuzzy** (`0.1745`).

Лучшая классическая модель в этом прогоне — `random_forest_regressor` (`RMSE = 0.1062`). Это подтверждает прикладную конкурентность нейро-нечётких архитектур при сохранении интерпретируемой rule-based структуры.

## Вывод для позиционирования статьи

Полученные результаты подтверждают корректность выбранной экспериментальной рамки: stacked и hierarchical ANFIS являются сильными baseline-архитектурами, а DFFL остаётся архитектурно и интерпретационно значимой линией, особенно когда критерий выбора включает не только «чистое» качество, но и устойчивость структуры объяснений.

Для финальной версии статьи рекомендуется явно формулировать multi-objective критерий (quality + complexity + stability), а не опираться только на single-metric лидерство.

## Готовый фрагмент для раздела Results (черновик)

В серии экспериментов на пяти реальных табличных датасетах (3 seed) мы сравнили четыре нейро-нечёткие архитектуры: shallow fuzzy, stacked ANFIS, hierarchical ANFIS и deep fuzzy feature learning (DFFL). Качество оценивалось по RMSE (регрессия) и F1 (бинарная классификация), структурная сложность — по размеру rule base, устойчивость — по межсидовой стабильности активных правил (Jaccard).

Интегрально по quality-критерию лучший средний ранг показала модель Hierarchical ANFIS, тогда как наибольшую устойчивость структуры правил продемонстрировала Shallow Fuzzy. При этом лидеры по отдельным датасетам различаются, что подтверждает необходимость multi-objective анализа при выборе финальной архитектуры для практического применения.

Таким образом, экспериментально подтверждается, что сравнение deep neuro-fuzzy архитектур должно учитывать не только точность, но и цену интерпретации: размер активного rule base и стабильность объяснений между запусками.
